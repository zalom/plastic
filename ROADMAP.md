# Roadmap

Plastic plans and tracks delivery in waves: a roadmap is a collection of
intents ordered toward one plain goal, delivered wave by wave. This file
mirrors the live roadmap of the current line; the shipped detail per release
lives in [CHANGELOG.md](CHANGELOG.md).

## Stable 1.0

Goal: every intent in the collection delivered or explicitly abandoned, the
full test suite green, an outsider able to install Plastic and deliver work
guided or auto without studying internals, loop engineering shipped inside
the stable line, and a 1.0.0 release cut and tagged.

- [x] Wave 1: foundations (roadmaps, gate fix, proportional cycle tiers)
