# Roadmap

This file is history: the roadmap toward the 1.0 stable line, kept as it stood. It is not
updated for 2.0. The shipped detail per release lives in [CHANGELOG.md](CHANGELOG.md), and
project roadmaps now live in each store's `roadmaps/` directory (see `plastic help roadmaps`).

## Stable 1.0

Goal: every intent in the collection delivered or explicitly abandoned, the
full test suite green, an outsider able to install Plastic and deliver work
guided or auto without studying internals, loop engineering shipped inside
the stable line, and a 1.0.0 release cut and tagged.

- [x] Wave 1: foundations (roadmaps, gate fix, proportional cycle tiers)
- [x] Wave 1b: mid-run amendments and fast-follows
- [x] Wave 2: trust fixes a newcomer hits in week one
- [x] Wave 3: lighten the felt process
- [x] Wave 4: guides and first sight
- [ ] Wave 4b: sell surface (README positioning, demo clips)
- [ ] Wave 5: plugin and marketplace direction (human decision)
- [ ] Wave 6: loop engineering
- [ ] Wave 7: intelligence foundation (database layer, MCP server, observers)
