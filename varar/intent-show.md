# plastic intent show

`plastic intent show ID` prints one intent's status, criteria, decisions, rulings, nodes and its last savepoint line. The rows below run the storage kernel's command line in a fresh home each time, as session s-1. A setup lists the calls made first, in order, split by a semicolon; `write PATH TEXT` writes a file in the store instead. TIME stands for a timestamp.

Each row gives the setup, the call, the exit code, the result and the next line:

| setup                                                                                                                                                                                        | call          | exit | result                                                                                                                       | next line                               |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- | ---- | ---------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| intent new Alpha                                                                                                                                                                             | intent show 1 | 0    | intent: 1 Alpha (open) / criteria: 0 / savepoint: TIME Opened: Alpha                                                         | plastic intent brief 1 --project global |
| intent new Alpha ; write store/1--alpha/spec.md "# Spec\n\n## Done criteria\n\n- [tests-pass] the CLI ships\n" ; sync up ; intent rule 1 "ship the CLI first" ; node add 1 Build --criterion tests-pass | intent show 1 | 0    | `intent: 1 Alpha (open) / criteria: 1 / ruling: D1 ship the CLI first / node: n1 open Build / savepoint: TIME Opened: Alpha` | plastic intent brief 1 --project global |
| none                                                                                                                                                                                         | intent show 9 | 1    | no intent 9 in this store                                                                                                    | none                                    |
