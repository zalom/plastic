# plastic backup restore

`plastic backup restore --store SLUG (--timestamp STAMP | --latest)` puts the databases of one done backup back, after a safety backup of the current ones, and `--dry-run` previews it. A restore never syncs by itself and asks no question: it replaces the databases and the next line is the sync down call for the same store. The rows below run the storage kernel's command line in a fresh home each time, as session s-1. A setup lists the calls made first, in order, split by a semicolon; `register SLUG` lists a store in `projects.yml`. STAMP stands for the 14-digit UTC folder name.

Each row gives the setup, the call, the exit code, the result and the next line:

| setup                                                                    | call                                            | exit | result                                                                                                                                                                                                                                        | next line                                     |
| ------------------------------------------------------------------------ | ----------------------------------------------- | ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| register alpha ; intent new Alpha --project alpha ; backup --store alpha | backup restore --store alpha --latest           | 0    | restore: backed up the current databases as STAMP / restore: knowledge_graph from STAMP / restore: references from STAMP / restore: work_graph from STAMP                                                                                     | plastic sync down --project alpha             |
| register alpha ; intent new Alpha --project alpha ; backup --store alpha | backup restore --store alpha --latest --dry-run | 0    | preview: restore knowledge_graph from alpha/STAMP / preview: restore references from alpha/STAMP / preview: restore work_graph from alpha/STAMP / preview: the current databases would be backed up first; the original store was not changed | plastic backup restore --store alpha --latest |
| register alpha                                                           | backup restore --store alpha --latest           | 2    | no done backup of alpha to restore                                                                                                                                                                                                            | none                                          |
