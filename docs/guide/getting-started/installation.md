# Installation

```bash
npx -y @zalom/plastic install --claude
plastic version
```

The first line installs Plastic for Claude Code. The second line confirms that the `plastic`
command runs.

[INSTALL.md](../../../INSTALL.md) covers Codex CLI, channels, a clean Mac, updates and
rollback. [SECURITY.md](../../../SECURITY.md) lists every place the installer writes.
