# Agent report: competitive landscape (competitors)

Full text as delivered 2026-08-02. Headline findings:
1. "Intent-driven development" as a TERM is claimed (intent-driven.dev, Hari Krishnan, updated 2026-06-29, defines IDD as umbrella over context engineering, SDD, harness engineering, Ralph loops; Sean Grove "The New Code" 2025 is the origin citation; Lahiri arXiv:2603.17150 "intent gap" academic framing; SpecStory tagline "intent is the new source code"). But the ARTIFACT is unclaimed: almost nobody ships intent as typed durable first-class artifact; only 4 repos do, largest 495 stars.
2. Capital skipped the middle of the unit-of-work spectrum: money went to PR (CodeRabbit $88M, Qodo $120M, Graphite $81M) and session/workspace (Devin $26B val, Conductor $22M, Factory $150M). Durable human-legible work item owned intake-to-merge: only Augment Cosmos (enterprise) and Linear AgentSession. That is Plastic's opening.
3. Plastic 9 stars; field floor for relevance ~5k; Agent OS 5.2k is realistic near-term target, not Spec Kit 125k.
4. Consensus turning against heavy specs (ETH arXiv:2602.11988: context files don't improve success, +20% cost, repo overviews not helpful, imperative org-specific rules do help; Böckeler/Thoughtworks: SDD = Model-Driven Development risk, Kiro 16 acceptance criteria for small bugfix; Macedo arXiv:2606.04967 taxonomy: no framework excels across all dimensions, absent benchmarks for complete processes = biggest unclaimed credibility play).

Main table (stars verified 2026-08-02): Spec Kit 125k (specify→plan→tasks→implement; institutional distribution; verbose, no state between specs, no community). Superpowers 264.9k stars/137k+ installs (skills not documents; no persistent work store). GSD 64.8k ARCHIVED 2026-06-26 ($GSD token rug-pull ~$500k; fork open-gsd/gsd-core 7.6k). BMAD-METHOD 51.4k (12+ personas, Discord 15k, YouTube 20k subs; heavy for solo; zero monetization). OpenSpec ~28k (spec DELTAS, change-shaped not idea-shaped). Taskmaster 27.9k (tasks.json, dependency-aware next_task, MCP-native; Commons Clause, Hamster SaaS lane). CCPM (GitHub Issues as store). Agent OS 5.2k (standards-first; best monetization: $299/yr membership). Kiro (AWS, GA Mar 2026, EARS notation, IDE-locked, $19-200/mo). Conductor ($22M, worktree window manager, no lifecycle). Plastic 9 stars (only system with Zettelkasten graph store + deterministic hook gates + frontier advisor role).

Commercial agent-first PM: Devin (Session+Playbook, ARR $73M→$492M in 11mo), Linear for Agents (AgentSession typed lifecycle, agents delegated vs humans assigned, cleanest object model), Amp (Thread should replace ticket), Charlie $10M (Task→Run→Turn durable runtime), Augment Cosmos (Ticket, enterprise), Traycer ~302k installs (explicit "Intent Clarification" stage), Factory $150M (--use-spec forbids edits until spec agreed).

Standards war: AGENTS.md (23.4k, Linux Foundation AAIF, but no actual spec, Claude Code doesn't read it) vs Agent Skills/SKILL.md (23.7k in 7mo, real spec, read by Anthropic/OpenAI/Copilot/Gemini/Cursor/Kiro/Amp: quietly won). Distribution moved to reviewed marketplaces. Verb set standardized: ready/next → claim → close, --json + token-compact output.

Positioning, unique to Plastic: intent-as-desire (open), Zettelkasten graph store (unique at any scale), idea development incl. parked future intents (sharpest gap: every competitor starts at "I know what to build"), deterministic hook enforcement (near-unique; cc-sessions DAIC died Dec 2025), frontier advisor role (unique, monetizable), outcome.md as truth incl. abandonment (unique; audit-trail story enterprises will want).

Gaps: traction (critical), marketplace presence (critical, highest-leverage single action; Superpowers 137k installs from one listing), quotable number (critical; every spike had named enemy + before/after), video (high; 70% devs learn via YouTube), multi-user (high), IDE surface (medium, probably skip), ceremony perception (medium; Plastic has MORE stages than Spec Kit which is already criticized), governance (medium; GSD lost 88% of stars to single-maintainer collapse; move to org + second maintainer), benchmarks (opportunity: first credible benchmark is category-defining).

Honest risk: process depth is differentiator AND adoption tax; most-copied artifacts in field are two md files with zero install and one bash line. Winners are understandable in 90 seconds. Plastic needs a 90-second surface over a deep engine.

GTM ranked: 1) plugin marketplaces (Claude Code first-party + 2,307-plugin community mirror, Cursor 2.5 plugins, awesome-copilot; only step-function channel). 2) Ship the benchmark nobody has (Plastic vs Spec Kit vs BMAD vs GSD vs bare Claude Code, published data; converts weakness into testable claim). 3) Earn one high-trust endorsement (Willison pivot for Superpowers, 435-pt HN; targets: Willison, Osmani, Huntley (his thesis!), Böckeler as skeptic-to-convert). 4) Name the enemy + attach a number ("the idea that dies in a chat log" / "work that ships with no record of why"; context rot is taken). 5) One long honest build-log blog post with real transcript. 6) YouTube with quantified outcome in title (compounding, 2 quarters to effect; Taskmaster wave was other people's videos). 7) LinkedIn as curriculum not feed (82% of B2B social leads; personal profile 8x company page; Spec Kit's LinkedIn Learning course is the proven tactic; individuals are in r/ClaudeCode 4,200 weekly contributors + r/ChatGPTCoding 383k + YouTube; for companies sell outcome record + audit trail as governance). 8) Fix governance before needed (org namespace, second maintainer, governance note; an afternoon that insures everything).
Not recommended: Discord (retention not acquisition), podcasts (after ~30k stars), newsletters, paid ads.
Monetization shapes: Casel (free repo → $299/yr membership; closest fit given LinkedIn position + enterprise governance angle), Toledano (Commons Clause → SaaS), Vincent (MIT → enterprise services), Madison (none forever). GSD's token = the one incoherent shape, killed the project.
